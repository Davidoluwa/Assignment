Open world game for mobile

Original game · custom C++ engine · OpenGL ES 3 · in development

My own game on a custom engine, with no Unity or Unreal underneath. It runs on mid-range Android phones and is tuned against real device logs, one release at a time.

  • Renderer built for phone GPUs: shadow maps, instanced and frustum-culled world, 4x anti-aliasing resolved on-chip, tone mapping inside each shader
  • Two worlds, a city campus and a forest, loaded through a streaming world grid with baked levels of detail
  • Skinned characters with generated skin, hair and cloth materials
  • Physics through Jolt: character controller, ragdolls and vehicles
  • In-game GPU benchmark and profiler, memory trackers, and a headless desktop build for repeatable screenshots and shader checks
